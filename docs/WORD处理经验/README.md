## 什么时候来查

改导出链路之前，先扫一遍坑位表，很多坑是同一个根因的不同表现。产物交付之前，
按核对方法走一遍 Word 回读，不要只看 XML。

## 维护约定

- 新坑随手记一条，写清现象与依据，别只写结论；
- 解法落在代码里的，记下文件与函数名，方便日后回溯；
- 脚本一旦长期要用，先判断要不要随仓库走。入库的进 `scripts/`；只在本机用的进
  `localscripts/`，单测、E2E 探针、Word 核对脚本、开发工具都属这一类。两种都登记到
  脚本手册，本机目录不入版本库。
