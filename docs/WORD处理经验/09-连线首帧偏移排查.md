# 09 - 连线"显示偏移"排查（数据对齐 ✓、显示不对 ✗）

> 现象：转换侧自检（`connector-align.mjs`）报**最大轮廓偏差 0.00pt** ✓，但在 Word 里双击看图，
> 连线仍有偏移/错位 ✗。本文记录 2026-09-28 的取证与结论，供两侧对齐口径。

## 1. 先排除"我们这一侧"（消费端）

`packages/postprocess` 对 vsdx 是**字节透明**的：只做三件事 —— 剥缩略图、
（可选的）页面尺寸修补（默认关）、写 OLE 容器。实测：

| 检查 | 结果 |
| --- | --- |
| 服务直出 vsdx → 写进 docx 的内嵌件 | 形状数 / Connects / 母版数 / 字节数**逐项一致** ✓ |
| 转换侧自检 `docx-embed-all.mjs`（23 个内嵌件） | 连线 3~14 条、Connects 成对、母版 4 个 ✓ |
| 转换侧自检 `connector-align.mjs`（23 个内嵌件） | **最大轮廓偏差 0.00pt**、几何端点偏差 0.00pt ✓ |

⇒ 数据侧已经对齐 ✓，问题不在这条链路上。

## 2. 取证：形状的"写实程度"

用 `temp/工具/查写实程度.cjs`（本机脚本）逐形状统计关键 Cell 与 Section：

| 项 | 节点形状 | 连线形状 |
| --- | --- | --- |
| 自带 Geometry 段 | ✓ 全部 | ✓ 全部 |
| PinX/PinY/Width/Height/LocPinX/LocPinY | ✓（但带 `F="Inh"`） | ✓（但带 `F="Inh"`） |
| BeginX/BeginY/EndX/EndY/EndArrow | —（不需要） | ✓ |
| **Angle** | ✓ 5/5 | **✗ 0/4（靠母版继承）** |
| `<Section N="XForm">` 段 | **✗ 页面里 0 个**（Cell 裸写在 `<Shape>` 下） | 同 |
| Line/Char/Fill 段 | ✗ | ✗ |

连线母版（`master50.xml`）里：`Angle = GUARD(0DA)`、`Width = GUARD(EndX-BeginX)`、
`PinY = GUARD((BeginY+EndY)/2)`、`LocPinY = GUARD(Height*0.5)` —— **这些赋值都以公式形式留在母版**，
页面形状只写了缓存值 `V` 且带 `F="Inh"`（继承公式）。

## 3. 结论（与 05 号同源）

`docs/WORD处理经验/05` 已经证实过：**Visio 的首帧渲染不解析母版继承** —— 当时的表现是
"背景框尺寸离谱，缩放一次才正常" ✗。这次是同一类：

- 连线的 `Angle` **完全没有写实** ✗，`PinX/PinY/Width/Height/LocPinX/LocPinY` 的**公式仍标 `F="Inh"`** ✗；
- 页面里没有任何 `<Section N="XForm">` 段 ✗（Cell 裸写），也不是标准 vsdx 形状的写法；
- 于是"数据算出来是对的（离线解析器按公式算 ⇒ 0.00pt ✓）"，但**首帧按母版默认值摆放** ⇒ 显示偏移 ✗。

## 4. 给生成侧的最小修法（与 05 号节点写实同口径）

1. **写实 XForm**：`PinX/PinY/Width/Height/LocPinX/LocPinY/Angle` 全部写成**普通值**（不要 `F="Inh"`），
   并且**放进 `<Section N="XForm">`** 里；连线的 `Angle` 必须显式给（哪怕 0）；
2. 连线的 Geometry 段保持现在这样（已被 `da6c50a` 对齐）✓；
3. `Line`（含 `EndArrow/BeginArrow`）、`Char`、`Fill` 等首帧会用到的项，同样写实到形状上，
   别只留在母版；
4. 自检加一条：**页面形状里不允许出现 `F="Inh"` 的 XForm 类 Cell**，且每个 `<Shape>` 都必须有
   `<Section N="XForm">` —— 这条能直接卡住"数据对、显示不对"这一类问题。

## 5. 复现与验证（本机脚本）

```powershell
# 逐形状看写实程度（节点 vs 连线）
node temp/工具/查写实程度.cjs "<内嵌件>.vsdx"
# 数页面/母版里的 XForm 段与 Angle
node temp/工具/查段与母版.cjs "<内嵌件>.vsdx"
# 打印某条连线的完整 XML
node temp/工具/看一条连线.cjs "<内嵌件>.vsdx" 2
```

判据：修好之后，`查段与母版.cjs` 里 **XForm 段数应等于形状数**、`Angle` 数应覆盖所有连线；
再按 05 号的办法在 Word 里双击看首帧是否直接正确（不需要缩放一次）。
