- `WORD解压结构研究` 是唯一事实源，实现与验收都对着它，不对着历史产物；
- `版本开发过程` 是历史材料，不回溯改写，要更正就在新文档里说明；
- 素材原文与外部版权内容一律不进仓库，回归数据只用 `samples/` 里的合成件；
- 「已讨论、暂不实施」的功能立项不进仓库，由维护者在本机保存；
- 单测、E2E 探针与冒烟、Word 核对脚本、开发工具都不进仓库，统一放本机的
  `localscripts/`，跑法与边界见 `docs/AI开发约定/项目特定规范.md`。
