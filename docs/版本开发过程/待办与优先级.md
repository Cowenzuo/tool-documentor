## A 级 · 交付物直接相关，先做

1. **安装包实机装一次**。`0.1.3-alpha1` 已经打出来并验过（`pnpm verify` 门禁、`package:dir` 产物校验
   —— 顶层依赖 135 个、`mmd2vsdx` 条目 0、`app.asar` 81.5 MB，随后出的 NSIS 安装包 131,680,980 字节），
   但**从没在本机真正安装过** —— 开始菜单、卸载、数据目录这三处还没人走过一遍。
   版本与成品位置见仓库根 `README.md` 的"打包与安全"一节。

2. **图转换服务：把它带给用户，并让 Chromium 装得上**。接入那半边已经交付：软件会自动找运行环境
   （没装系统 Node 就用应用自带的，实测可用）、把路径填回设置、一键「启动服务」。
   剩下的全是**分发**：服务程序现在得用户自己放到某个目录（软件不随包带，见
   [DESIGN-07-导出、题注与图嵌入.md](DESIGN-07-导出、题注与图嵌入.md) 第 7 节），
   首次还要跑一次 `npx playwright install chromium`。
   触发条件：真要在别人机器上开箱即用（前提是上游提供不含官方母版的发行形态）。
   届时可选：随包带一份 tarball 落到固定目录、由软件代跑一次浏览器内核安装，
   或让服务自己做成常驻自启 —— 软件那边只改"去哪找"。

## B 级 · 写作效率，等触发条件

3. **正文里插图表交叉引用**。题注域已就绪，Word 能识别图表编号，缺的是正文里那条指向
   以及题注书签。触发条件：要在正文里写"见图 3"，而不是在 Word 里手动插。
4. **表格手动合并与新建表格的合并预设**。判定与"勾选即合并"已交付，
   缺的是点选相邻单元格的交互。触发条件：自动判定不够用。
5. **写入失败时界面不回滚本地编辑**。失败会弹主进程给的原因，数值要等下次对账才回退。
   现状与修法见 [DESIGN-08-撤销与重做.md](DESIGN-08-撤销与重做.md)。
6. **模板新建不校验默认样式是否存在**。接口层能传进不存在的 uuid，写出一份"出生即悬挂"的
   模板；界面上是下拉选已有样式，走不到这条路。
7. **本机自检目录整目录备份**。十一份自检与单测都是发布门禁，全部在 `localscripts/`、不入库，
   这台机器出事就没了。低成本，随时可做。
8. **图转换的批量端点与导出进度**。一篇 258 张图的文档现在约 10.7 秒、界面无进度反馈
   （2026-09-23 实测，见 [DESIGN-07-导出、题注与图嵌入.md](DESIGN-07-导出、题注与图嵌入.md) 第 6 节），
   当前接受。触发条件：有人抱怨导出慢或"像卡死了" —— 第一件事是找上游加 `/convert/batch`，
   第二件才是给导出加进度。
9. **顺手改、不单开一轮的几条**：模板校验的目录规则粒度（两种缺失并成了一条）、
   `packages/docx` 的 `clonedGroups` 改名、工程工作区的写入命令加一条按内容搬运的换类型、
   撤销后选中项写回 `ui_state`。

## B2 级 · 整理文档时翻出来的小问题

都不影响现在的用法，记下来是免得下次重新发现一遍。

10. **界面在"编辑关"时输入框仍可打字**。输入框的只读只看块档位，没把节点的「编辑」总闸算进去，
    打得进字、写入侧才拒绝，那些字不落库。当前碰不到：七份真实工程里「编辑」关着的章节
    一个内容块都没有。详见 [DESIGN-06-权限与锁.md](DESIGN-06-权限与锁.md)。
11. **`TemplateManager.validateStyleTemplate` 已无调用方**，且与 `validate.ts` 里的同名函数
    规则不同（不查样式键全集）。要么补一个调用场景，要么清掉。
12. **`buildTreeFromInstance` 已无调用方**，且不带 `lock`、`allowLayoutEdit`、`rowSpans`
    这些后加的字段。仓库里确实没有调用点，只剩本机工具 `localscripts/tools/test-export.cjs`
    用它按实例 JSON 做无界面导出对照 —— 实例 JSON 这条通道是唤醒还是退役，要定一个。
13. **表格 `rows` 声明多于实际行数时不提示**。`checkTableShape` 只在"声明少于实际"时说话，
    多一点声明则静默。要不要也提醒一句。
14. **模板侧的表格列数没有界面守卫**。工程侧的表格编辑器卡住 `cols >= 1`，
    模板编辑器的表格网格与实例 JSON 通道没有，靠保存时的校验兜住。
15. **根节点的四个开关在界面上没有说明**。根不参与复制与裁剪，但「编辑」「排版」对根底下
    的块生效；界面上只说了前一句。
16. **结构规则有两份实现，靠人工对齐**。渲染层那份镜像没有"两边结论逐条一致"的对照测试，
    只有注释声明；样式侧不存在这个问题。

## C 级 · MCP 接口

17. **让内网大模型直接驱动软件**。战略上最大的一件事，卡在两个前提：内网给出可用模型与
    接入要求；四个边界先定下来——权限（模型能改到什么程度）、落点（改内存还是落库、
    要不要人确认后提交）、审计留痕、导出副作用。
    现在能做的只有不依赖模型的那一半：定边界，并照 `packages/desktop/src/shared/project.ts`
    现有的 IPC 通道与 DTO 列一份工具表。模型一到就能开工。
