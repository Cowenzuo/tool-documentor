# Documentor 重写 · 界面重设计方案（Web 自由设计）· 定稿版

> 对象：原 Qt 界面（02-界面规格.md）的重新设计。
> 原则：**不复刻像素，复刻能力与信息结构；用 Web 的自由度做出更好看的文档工具**。
> 评审定稿：主布局=结构栏+节点页+检查器；主色=C 紫蓝科技；P1 增强项全量采纳（排期见 PLAN-01 §6 里程碑）。

---

## 1. 设计目标

1. 一眼"专业文档工具"：克制、清晰、密度适中；规范/正式文档场景 → 秩序感优先，不做花哨。
2. 编辑效率高于旧版：常用操作 ≤2 步可达，块操作行内完成，无需滚到面板底部找按钮。
3. 深/浅双主题同为**一等公民**，通过 CSS Variables token 层实现，切换无闪烁。
4. 可访问：对比度达标、焦点可见、支持 `prefers-reduced-motion`。
5. 交互模型贴近 Notion/语雀/Linear 一代：内容即编辑对象，选中态与悬停态精致。

## 2. 信息架构与主布局（定稿）

```
┌────────────────────────────────────────────────────────────────┐
│  Titlebar（自绘）● ⚙ 主题⇄  · Documentor — <工程名>      ─ □ ✕ │
├─────────┬──────────────────────────────────────────┬───────────┤
│ 结构栏    │  节点文档页（编辑主体）                      │ 检查器     │
│ (可折叠) │  ┌ 标题行 + 节点徽标(类型/标志)            │ (可折叠/   │
│ 🔍 搜索 │  │ 内容块流：                              │  可拖宽)   │
│ ▾ 1 范围 │  │  · 文本块(卡片, 多行输入即文档外观)      │ 节点信息   │
│   ▸2 引用│  │  · 表格块(就地编辑, 悬浮工具条)          │ 块清单/导航 │
│   ▸3 概述│  │  · 图片/代码/公式/Mermaid/列表…         │ 文档统计   │
│  ＋ 复制 │  └───────────────────────────────────────┘ │ 视图切换   │
│  删除    │   底部: 添加内容块 (类型菜单)               │ 编辑⇄预览  │
└─────────┴──────────────────────────────────────────┴───────────┘
```

要点：
- **结构栏**（左）：文档树。节点图标按 nodeType 区分；标题编辑后原位刷新；
  搜索/过滤即时定位；右键菜单（复制/删除，可用性依 copyable/deletable）。
- **中区 = 节点文档页**：树选中一个节点，中区呈现该节点的"页面"——
  标题（大字号、行内编辑即 QLineEdit 等价）、节点徽标（类型/允许内容块等只读信息以
  徽标+Tooltip 呈现，替代旧版 3 个只读 checkbox 的笨重感）、内容块流。
- **内容块 = 统一卡片视觉**：块头（类型图标 + 标签 + 上移/下移/删除，悬停浮现，旧版常显 → 悬停浮现减少视觉噪音）+ 块体编辑器。
  高度拖拽手柄改为：悬停出现底部 grip 拖高（保留最小高 60px 语义）。
- **检查器**（右）：节点元信息（类型、标题层级、标志、description），块概览跳转，
  视图切换（编辑 ⇄ 预览）；宽度可拖，可整体折叠（不锁死比例——旧版"栏不可折叠"是 Qt 时代妥协，Web 无此必要）。
- **窗口级**：无边框自绘标题栏（Windows/Linux），macOS 用原生 traffic lights；
  文件菜单收敛为顶部工具条按钮组（保存 Ctrl+S、导出 Ctrl+E、设置）+ 标题栏菜单（后续）。
- **中区预览视图**（定稿）：切换"编辑/预览"，预览以静态文档样式渲染节点页
  （图片、表格样式化、Mermaid 渲染图、代码样式化），所见接近导出正文。

### 欢迎页（重设计）

        Documentor

┌──────────────────┬──────────────────┐
│ 新建工程  (主)    │ 最近工程          │

## 3. 视觉语言

### 3.1 布局与层级 token

| token 组 | 取值 |
|---|---|
| 圆角 | 控件 6px / 卡片 8px / 浮层 10px（浅色略大 +1） |
| 间距 | 4/8/12/16/24 阶梯（密度 = 紧凑偏中） |
| 阴影（深色） | 浮层 `0 8px 24px rgb(0 0 0 / .45)`，卡片基线仅 1px 描边不用投影 |
| 边框 | 深色 `--border: 1px solid rgb(255 255 255 / .08)`，浅色 `rgb(15 23 42 / .10)` |
| 字体 | UI：系统栈（Segoe UI / Microsoft YaHei UI / PingFang SC）；代码/公式：JetBrains Mono / Consolas；正文宋体回退交给导出，界面保持无衬线（清晰优先） |
| 字号 | 12/13(正文 UI)/14(输入)/16(区块标题)/20(节点页标题)/28(欢迎页主标) |

### 3.2 深色主题色板（dark）

| 角色 | 色值 |
|---|---|
| 背景底色 | `#0f1115`（近黑蓝） |
| 面板/卡片 | `#161a21` / 卡片悬浮 `#1c212b` |
| 输入/悬停行 | `#1d2330` |
| 文本主/次/弱 | `#e8eaed` / `#9aa3b2` / `#626b7a` |
| 描边 | `rgb(255 255 255 / .08)` |
| 强调（accent 定稿 C） | `#7c8cff`（hover `#93a1ff`），成功 `#3fb68b`，危险 `#f0616d`，警告 `#d9a441` |
| 品牌渐变 | `linear-gradient(135deg, #8b5cf6 0%, #6366f1 55%, #7c8cff 100%)`（仅 logo/主按钮光晕/欢迎页点缀） |
| 焦点环 | 强调色 50% 透明度 2px |

### 3.3 浅色主题色板（light）

| 角色 | 色值 |
|---|---|
| 背景底色 | `#f6f7f9` |
| 面板/卡片 | `#ffffff` / 悬浮 `#f0f2f5` |
| 文本主/次/弱 | `#1c2129` / `#5b6472` / `#8a94a3` |
| 描边 | `rgb(15 23 42 / .10)` |
| 强调（accent 定稿 C） | `#5a68e0`（hover `#4a56c4`） |
| 品牌渐变 | `linear-gradient(135deg, #7c5cf0 0%, #5a68e0 60%, #4f86ff 100%)`（仅点缀用） |
| 焦点环 | 同深色规则 |

> 使用纪律：**正文操作/选中态一律用纯 accent 色**（保证对比度），渐变仅用于品牌点缀
> （logo、欢迎页主视觉、主按钮按下光晕），防止"紫渐变界面"廉价感。

### 3.4 主题机制（定稿）

- token：`:root[data-theme=dark|light]` 挂全部语义变量；组件只引用变量名，不出现裸色值。
- 默认跟随系统 `prefers-color-scheme`；手动切换记忆持久化（localStorage + config 同步），切换 150ms 过渡。

### 3.5 图标与动效

- 图标：线性 1.5px 图标集（自绘 ~40 个 + 块类型 8 个专用图标），不用 emoji 拼界面。
- 动效规范：hover 80ms / 展开折叠 150ms ease-out / 模态 200ms 淡入+上浮 8px /
  主题切换 150ms。`prefers-reduced-motion: reduce` 时全部置零。
- 状态反馈：保存/导出成功用瞬态 toast（右下），错误用红色 toast + 操作点抖动提示。

## 4. 逐界面重设计规格（对照 02 界面清单，全部定稿）

| 旧界面 | 新设计 | 能力等价点 |
|---|---|---|
| 欢迎页 | §2 设计（主次按钮、模板入口前置、最近工程） | 新建/打开/设置全保留 |
| 模板选择对话框 | 全屏向导页（左列表右详情 + 工程名内联校验） | 重名校验、模板卡片选中态 |
| 主窗口 | §2 布局（结构栏/节点页/检查器） | 菜单功能进顶部工具条；标题"Documentor — <工程名>" |
| 文档树面板 | 结构栏（icon 分型、折叠箭头、右键菜单、搜索） | 复制/删除权限、全展开、恢复选中 |
| 属性面板卡片组 | 节点文档页 + 检查器拆分：编辑即页面主体，只读元信息进检查器 | 标题行内编辑、标志徽标化、collectEdits 语义不变 |
| 内容块编辑器 ×8 | 卡片化块流 + 各类型专属交互（§4.1） | 类型约束（行列范围等）不变 |
| 导出对话框 | 紧凑模态：格式单选(DOCX 可用/Markdown 预留禁用)、样式模板下拉去重、路径+浏览、导出 | 逻辑一致 |
| 设置对话框 | 模态页面：默认工程目录、模板目录列表增删；空回退内置提示 | 配置语义一致 |
| 图片全屏预览 | Lightbox：滚轮缩放 / 拖拽平移 / Esc 关闭 / 缩略图浏览 | 缩放拖动等价 |
| 无边框外壳 | 统一窗口壳组件（自绘标题栏 + 内容） | 模态壳共用 |

### 4.1 八种块编辑器的 Web 交互（定稿含全部增强）

| 块 | 交互设计 |
|---|---|
| 文本 | 多行自动增高（上限内），文本即"预览"；工具栏（粗/斜等）不做（旧版纯文本，防扩散） |
| 图片 | 拖拽文件进块即导入（+原有按钮）；缩略图悬停放大浮层；点击进 Lightbox；题注输入即图名 |
| 表格 | 就地编辑网格：单击单元格编辑、**Tab/方向键迁移**、行/列头菜单（增删行/列、调序）；SpinBox 等价的行列数调整保留；题注在上（与导出一致） |
| 公式 | 等宽编辑（阶段一）→ **即时预览**（轻量渲染，导出仍走占位文本语义，视依赖评估定实现） |
| 代码 | 语言下拉 8 项 + 等宽编辑器 + **代码高亮**（Prism 按需加载，编辑态与预览态统一） |
| Mermaid | **左源码右实时预览分栏**（防抖渲染，本地缓存 hash 图）+ 点击预览图全屏查看；渲染失败内联提示；预览图缓存 `<工程>/mermaid/<hash>.png` |
| 有序/无序列表 | 每行一项输入 + 行操作（上移/下移/删除行），导出语义=每项独立段+独立 numId 组 |

## 5. 主题与导出的边界（硬约束）

- 导出不受主题影响：docx 样式来自骨架，与界面主题**彻底解耦**（防止"深色界面导出黑字文档"类事故）。
- 预览视图展示的是"文档内容"渲染，配色跟随界面主题但排版（缩进/题注上下/编号）与导出规则一致，
  便于早发现排版问题——但预览永不为导出样式权威，权威是 M4 的旧版产物对照。
