# 界面结构

> 本文写界面的当前结构：有哪几张脸、每张脸怎么分区、结构与节点页怎么交互、模板编辑页与工程编辑器的分界在哪、各类界面状态存在哪里。
> 视觉 token 与主题机制也在本文；权限标签与置灰规则见 [DESIGN-06-权限与锁.md](DESIGN-06-权限与锁.md)，模板编辑器的功能面见 [DESIGN-03-模板体系.md](DESIGN-03-模板体系.md)。

## 1 壳层与四张脸

`App.tsx` 的 `Shell` 决定屏幕上出现什么，判断只有两条：

```
TitleBar（常驻）
templateEditorOpen ? TemplateEditorPage
                   : session ? Editor
                             : Welcome
ToastHost（常驻）
settingsOpen && SettingsModal
exportOpen && session && ExportDialog
```

**要点**：模板编辑页是整页，它挡在最前面时**不渲染编辑器、也不退出已打开的工程**；设置与导出两个弹层挂在壳层而不是标题栏里，否则会被标题栏的拖拽区吃掉点击。主题上下文 `ThemeProvider` 在 `AppProvider` 外层，所以主题切换与有没有工程无关。

## 2 欢迎页

欢迎页是左右分栏：左边品牌区，右边最近打开。

- 品牌区：品牌字形、`Documentor`、版本号（`app:get-info`，取不到时用一份兜底常量）、副标题「模板驱动的结构化文档写作台」，以及三个按钮——**新建工程**（主按钮）、**打开工程…**（走 `dialog:select-dproj` 拿路径再打开）、**模板编辑**；
- 最近打开：来自 `settings.get().recents`，每条显示工程文件夹名（路径的倒数第二段）与全路径，点击直接打开；列表为空时显示「暂无最近打开的工程」。

模板编辑的入口放在欢迎页而不是设置里，是因为它与工程无关：不打开工程、不进撤销栈，没必要先新建或打开一个工程再绕进去。

新建工程走模态向导 `CreateProjectWizard`：工作区目录（默认取设置里的默认工程目录）、工程名、模板卡片网格（按 `category` 出筛选按钮，卡片显示名字、说明、版本）。创建按钮的可用条件是三个字段都有值且不忙。**模板一套都没有时不给空白**：向导把「哪个目录、为什么没加载到」直接摆出来（没配目录 / 目录不存在 / 加载器报的第一条原因）。

## 3 标题栏

窗口是无边框的，标题栏自绘，分三区：

| 区 | 内容 |
| --- | --- |
| 左 | 品牌字形 + `Documentor` |
| 中 | 工程名（没有工程时这一格空着，且对读屏隐藏） |
| 右 | 保存、导出、定位、退出、分隔线、设置、窗口控制（最小化/最大化还原/关闭） |

有工程时才出现的是保存、导出、定位、退出四颗按钮；设置与窗口控制一直有（macOS 走原生红绿灯，不画窗口控制）。`document.title` 同步成 `Documentor - <工程名>`，任务栏与窗口列表里才认得出开的是哪个工程。最大化状态由主进程推送（`window:maximized-changed`），按钮图标跟着换。

**主题切换不在标题栏**：它已经收进设置对话框的「主题」分段控件（跟随系统 / 浅色 / 深色）。位置变更是有意为之——三个选项需要一个能看出当前值的位置，标题栏那颗按钮只能循环。

## 4 编辑器：两栏 + 工具行 + 状态栏

主编辑界面是**两栏**：左边结构栏，右边文档舞台。三列的网格是 `<结构栏宽> 5px 1fr`，中间那条是拖拽分隔条（`role="separator"`）。

- 结构栏宽度 180–520 px，默认 272，拖动结果记在 `localStorage` 的 `layout.treeWidth`；
- 舞台顶部一条工具行：**左**是撤销/重做与历史面板（`HistoryControls`），**右**是编辑⇄预览的视图开关（`ViewToggle`）；
- 舞台主体按视图渲染 `NodePage` 或 `PreviewPage`；
- 底部是状态栏：`N 章节 · M 项内容`，以及模板名与工程目录；模板认不到时写「模板未认到」，不写空——空着看不出是没配模板还是界面坏了。

视图选择**按工程记**：`ui_state` 的 `editor_view` 键，切工程时重新读。切换视图前先 `flushAll()` 提交挂起编辑，否则预览读到的是防抖缓冲之前的数据。除了点开关，`Ctrl+P` 也能切（应用没有打印功能，这个组合空着）。主进程忙时舞台盖一层 `busy-overlay`，不是把界面冻住。

## 5 结构栏（文档树）

结构栏顶部是搜索行：搜索框、命中计数、上一个/下一个命中按钮、层级折叠菜单。底部是树本体。默认**全展开**。

**折叠与展开**：

- 行首的三角展开/收起该节点；**按住 Alt 点击三角收起整枝**（长文档里逐级点太慢）；
- 层级折叠菜单给「全部展开」「全部折叠」以及「折到 N 级」（N 从 2 到树里最深的标题层级）；「折到 1 级」与「全部折叠」是同一件事，所以菜单里不重复列；
- 展开集合存 `ui_state` 的 `tree_expanded`（JSON 数组）。**没有记录才全展开；空数组是有效记录**，表示用户把树全折了；工程里已不存在的 id 在解析时丢掉，免得换过模板之后留下幽灵状态。

**搜索**：按标题子串匹配（已 trim 并转小写），一次前序遍历同时算出命中集合、按前序排好的命中序列、以及"要显示哪些行"（命中项加上它们的祖先）。搜索时只渲染这些行，命中子串用 `<mark>` 高亮，并自动滚到第一个命中；上一个/下一个命中到头回绕。搜索框里按 ↑↓ 也走进命中序列——搜索完最顺手的动作就是按↓，所以键盘处理挂在面板上而不是树容器上。

**键盘导航**（焦点在搜索框时只接管 ↑↓，左右与 Home/End 留给文本光标）：

| 键 | 行为 |
| --- | --- |
| ↑ / ↓ | 按当前可见行的前序移动选中项 |
| Home / End | 到第一行 / 最后一行 |
| → | 有子节点且收着就展开；否则进下一个可见行 |
| ← | 有子节点且开着就收起；否则回父节点 |

根节点没有折叠箭头——它永远画成展开的，要全折用工具栏那个菜单。

**右键菜单**有三项：**复制章节**、**裁剪章节**、**折叠该分支**。右键同时把该行选上，菜单里的操作对象与右侧编辑区看到的保持一致；按不了的项目灰着并把原因写在悬停提示里（根节点不能复制/裁剪、模板未开放复制/裁剪、该章节没有子章节）。菜单自己会按视口收边，打开后焦点落在第一个可用项上，↑↓ 走项，点外面或按 Esc 关闭。

**词的注意**：节点级的删除在界面上叫**裁剪**，与模板编辑器里那个开关、标题下那枚标签是同一个词。改文案时两侧要一起改。

## 6 节点页

节点页是「一个章节的纸面」，自上而下四段：标题行、节点徽标、编制说明、内容块流。

**标题行内编辑**：非受控 `input`（`key` 取节点 id，换章节就重建），改动走 600 ms 防抖提交，**失焦立即提交**；有挂起改动时标题右侧显示「编辑中…」，让人知道这串字还没进工程数据。撤销或重做会把整棵树换掉，所以外部改回来的标题要回写进这个非受控框——但正在编辑（本地脏）时不动它，免得打断光标。

**节点徽标区**：一个类型徽标（`文档根` / `列表子标题` / `标题级别 N`），后面跟着**只列"能做的事"**的权限标签：复制、裁剪、编辑、排版，四个都关时显示「内容只读」。以前把三个否定标签也摆出来，读着像出错。标签的词与悬停说明取自 `shared/permissionTerms.ts`，与模板编辑器的四个开关同一份。

**编制说明**：一个 `textarea`，随内容长高（上限写在 CSS 里，超出才内部滚动），走与标题同一条防抖与 flush 通道。历史数据里的「无」按空串处理。

**内容块流**：块与块之间、以及末尾各有一个添加入口。

- 块列表上方一条小工具行：`N 项内容` + 全部折叠/全部展开；
- 排版开着时，每块上方有「＋ 在此插入」，末尾有「＋ 添加内容」，两者弹出同一个类型菜单（八种块，顺序固定，按钮上带一句人话说明）；
- 每块是一张卡片（`BlockCard`）：折叠三角、类型徽标、**类型名按钮**（点开换类型菜单）、锁标记、折叠后的一行摘要、以及悬停浮现的上移/下移/删除；
- 卡片级快捷键：**Alt+↑/↓ 移动本块**、**Ctrl+Enter 折叠/展开**（事件从编辑器里冒泡上来，光标在文本域里也能用）；
- 换类型菜单按视口坐标摆（卡片自己有 `overflow: hidden`，摆在里面会被裁掉），当前类型那一项灰着；**会丢字的那几路先问一句**，把"丢什么"列在确认条上。

**块的前端稳定键**：块本身没有稳定 id，用下标当 React key 会让一次上移把两张卡片整体重挂载（光标、滚动位置、上传忙碌态全丢）。所以每块配一把 `crypto.randomUUID()` 的键，结构变更（增删移）由发起方登记一个 `StructureOp`，对账时按登记把键跟着搬；长度对不上就整批换新键——宁可重挂载，也不能张冠李戴。

**与主进程对账**：`NodePage` 同时比 store 侧的块序列签名与自己的镜像。只比 store 签名不够：用户刚打的字先落在本地缓冲里，store 还没动；这时若 store 的签名退回上一次对账时的值（撤销正是如此），按签名判就会跳过同步，用户看到「撤销没生效」。**块折叠状态按节点记在内存里**，切走再回来还认得，不进库。

## 7 预览视图

预览是**整篇**渲染，不是只看当前节点——章节之间的层级上下文与版面连续性只有连起来看才有。它按前序铺开全部节点，当前章节高亮并自动滚到它。

- 排版口径对齐导出：表题注在表上方、图题注在图下方且居中，表格的纵向合并走 `core` 的 `resolveTableMerges`（与导出同一个函数），代码走高亮、公式走 KaTeX 渲染；
- 正文栏宽按样式骨架的正文区算（`project.page-text-width` 给的 twips 除以 15 换成 px），拿不到就退回 CSS 兜底值；
- 块按需挂载：用 `IntersectionObserver` 在进视口前 600 px 才挂上，挂上不撤——否则上百张图的工程一进预览就要把所有图读成 dataURL；
- 预览顶部还会显示**导出前检查**的结果（图片找不到文件、流程图会以文本形式导出、表格超出行列上限）。这些是会影响导出结果的问题，不是常规计数；
- 图片读不到文件时说「图片文件缺失：<路径>」，不整块不渲染。

## 8 模板编辑页

模板编辑页是整页独立界面，可以从欢迎页的「模板编辑」按钮进，退出后回到原来那张脸。它的顶部左边是**模板目录下拉 + 重载按钮**，右端依次是草稿状态灯、试跑、保存、退出。

- **草稿状态灯三态**：红=有错误（挡住保存）、琥珀=有未保存的改动、绿=与文件一致。灯上只写最短一句（「3 个错误」「未保存」），完整理由在悬停提示里；
- **三栏**：左=模板列表（上半结构模板、下半样式模板，两段之间可拖分），中=节点树，右=选中节点的表单。左栏与中栏的宽度可拖，也可用键盘左右键各推 16 px，记在 `localStorage`；窗口变窄时按比例收左与中，先保右栏的最小可用宽度——要填的字都在右栏。样式模板打开时，对照表占中栏与右栏两栏的位置（一行五列，挤在窄树栏里没法看）；
- **页脚是这一页唯一的状态栏，固定一行高**，里面的东西再长也不许把它撑起来。这一条上的消息分三类：要你先点一下的确认（未保存改动 → 取消 / 丢掉改动并切换）、一次操作的回执（成功一行摘要，长内容点「详情」弹浮层）、校验小结（点开是"问题在哪"的索引，能跳的做成按钮直接跳到该节点）。

**与工程编辑器的分界**是这一页的设计前提：模板编辑有自己的状态与组件树（`useTemplateEditor` 与 `components/template/**`），**不碰 `AppContext`**，**不进撤销栈**，**不打开工程**，也不继承编辑器那套快捷键——`Ctrl+S` 与 `Ctrl+Z` 在模板编辑页打开时让位（这一页保存的是模板文件，不是工程）。这样划开是因为两边的语义相反：文档编辑是防抖写库、走会话级撤销栈、块带题注与图片导入这类文档语义；模板编辑是显式保存一个 JSON 文件。真按"编辑器加模式开关"做，等于在最复杂的那部分代码里插十几处分支。

模板编辑器能做哪些动作、校验怎么分层，见 [DESIGN-03-模板体系.md](DESIGN-03-模板体系.md)。

## 9 两个弹层

设置与导出是模态弹层，共用同一套外壳样式（遮罩 + 头部 + 内容 + 页脚），从标题栏进、点 ✕ 或「取消」出。

**设置**分四段：主题（跟随系统 / 浅色 / 深色）、默认工程目录（可浏览）、模板目录，以及底部动作。模板目录这一段是**配置 + 就地反馈**：每个目录一行输入框 + 浏览 + 移除，下面紧跟它在加载报告里的状态——目录不存在、未加载到模板，或「已加载 N 套结构、M 套样式」；少加载了什么一条一行地说，最多三条，多的折叠成一句「还有 N 条同类问题已省略」。保存后主进程即时重载模板并刷新报告，不需要重启。模板编辑的入口**不在这里**（在欢迎页），这一节只管配置。

**导出**分五段：格式（DOCX 可用，Markdown 预留且禁用）、样式模板下拉、图表嵌入提示、表格提示、输出路径（可浏览）。样式下拉列出模板目录里**能读出来的全部样式**，默认选中结构里写的那一份，可以改选；一份样式都没有时下拉禁用、导出按钮禁用，页脚写明原因。中间两段是只读提示，数字由 `export:figure-counts` 现算（要嵌几张图、流程图能不能转、表格是不是按 Word 原生表格导出）。导出成功用一条 toast 回执，文案里带图嵌结果与告警条数；**只有确有失败才用红色**，有提醒用琥珀色。导出链路的细节见 [DESIGN-07-导出、题注与图嵌入.md](DESIGN-07-导出、题注与图嵌入.md)。

## 10 主题与视觉 token

主题是**两套一等公民**，靠 CSS 变量切换，不靠组件分支：

- `styles/tokens.common.css` 放与主题无关的量：圆角（控件 6 / 卡片 8 / 浮层 10 px）、间距阶梯 4/8/12/16/24、UI 字体与等宽字体栈、字号 12/13/14/16/20/28、动效时长（hover 80 ms、展开与主题切换 150 ms、弹层 200 ms）、标题栏高度；
- `styles/tokens.dark.css` 与 `tokens.light.css` 各挂一份语义变量，选择器是 `html[data-theme='dark' | 'light']`：背景、面板、输入、三级文本色、描边、强调色与柔和强调、成功/危险/警告、子标题的五档层级色、滚动条、浮层阴影。**组件里只引用变量名，不出现裸色值**；
- 强调色深色 `#7c8cff`、浅色 `#5a68e0`；品牌渐变只用于 logo、欢迎页主视觉与主按钮光晕，正文操作与选中态一律用纯强调色，保证对比度；
- `ThemeProvider` 管三态偏好（system / dark / light），跟随系统靠 `matchMedia` 监听；偏好存 `localStorage` 的 `doc-theme`，挂到 `<html>` 的 `data-theme` 上。切主题时临时给根加 `theme-switching` 类（180 ms 后移除），让颜色过渡而不是硬跳；
- `index.html` 的 head 里有一段内联脚本，在 CSS 加载前就按偏好把 `data-theme` 挂上——否则冷启动会先闪一下另一种主题。生产 CSP 用 sha256 哈希放行这段脚本。

`base.css` 管重置、滚动条、`:focus-visible` 焦点环与主题过渡类；`app.css` 管壳层与两个弹层的骨架样式；各功能区自己的样式跟着组件走（`editor.css`、`tree.css`、`template.css`、`welcome.css`、`titlebar.css`）。可访问性上还有一条全局降级：`prefers-reduced-motion: reduce` 时动效全部置零。

## 11 内容块编辑器

八种块共用同一张卡片壳，块体各自一个编辑器，都在 `components/editor/BlockEditors.tsx` 里出（数据字段与落库口径见 [DESIGN-05-内容块与表格.md](DESIGN-05-内容块与表格.md)）：

| 块 | 界面上的样子 |
| --- | --- |
| 文本 | 多行自动增高的纯文本输入，不挂富文本工具栏 |
| 图片 | 缩略图 + 导入/更换/移除；拖拽文件进块即导入；点缩略图进 Lightbox |
| 表格 | 就地网格编辑，行列表头可改，Tab 与方向键在单元格间迁移，行列数受上限约束 |
| 公式 | 等宽编辑区，配一个编辑⇄预览的切换（预览走 KaTeX） |
| 代码 | 语言下拉（8 项）+ 等宽编辑器，另有只读高亮浏览视图 |
| 流程图 | 左源码右实时预览的分栏，防抖渲染；渲染失败内联提示；预览图可全屏 |
| 有序/无序列表 | 每行一项的输入 + 行级上移/下移/删除 |

**Lightbox**（图片与流程图共用的全屏预览）：滚轮缩放、拖拽平移、`Esc` 或点背景关闭，底部一行提示写清这三个操作。

## 12 状态存在哪

| 状态 | 存在哪 | 谁写、谁读 |
| --- | --- | --- |
| 会话（工程信息 + 文档树镜像） | `AppContext` 的 `session` | 打开/新建/撤销写入，全界面读 |
| 选中章节 | `AppContext` 的 `selectedId` | `selectNode` 写；同时写 `ui_state.selected_node` |
| 树的展开集合 | `TreePanel` 本地 state | 初始读 `ui_state.tree_expanded`，每次开合写回 |
| 内容块折叠 | `NodePage` 的 `collapsedByNodeRef`（内存，按节点） | 只在本会话有效 |
| 挂起编辑 | `NodePage` 的若干 ref + 定时器 | 防抖提交，切换/保存/撤销前 `flushAll()` |
| 编辑⇄预览 | `Editor` 本地 state | 初始读 `ui_state.editor_view`，切换写回 |
| 弹层开关（设置/导出/模板编辑） | `AppContext` 三个布尔 | 标题栏与欢迎页开，弹层自己关 |
| 历史栈状态 | `AppContext` 的 `historyState` | 每次变更后向 `history:state` 拉一次 |
| 主题偏好 | `ThemeProvider` + `localStorage` 键 `doc-theme` | 挂 `data-theme` 到 `<html>` |
| 界面宽度 | `localStorage`：`layout.treeWidth`、`layout.templateListWidth`、`layout.templateTreeWidth`、`layout.templateListPaneSplit` | 拖动或键盘微调后写 |
| 模板编辑草稿（结构 / 样式各一份） | `useTemplateEditor` 内部 state | 只改内存，点保存才写文件 |

一条纪律：**能被界面推导出来的东西不进库**。块折叠、栏宽、菜单开合都不落盘；只有"下次打开还得是它"的少量状态才进 `ui_state`。

## 13 快捷键

| 键 | 作用 | 例外 |
| --- | --- | --- |
| `Ctrl+S` | 保存工程 | 模板编辑页打开时不接管 |
| `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` | 撤销 / 重做 | 设置、导出、模板编辑页打开时不接管；捕获阶段拦下，不让浏览器改文本框自己那份 |
| `Ctrl+P` | 编辑⇄预览切换 | — |
| `Alt+↑/↓` | 移动光标所在的块 | 排版关着或块带锁时不动 |
| `Ctrl+Enter` | 折叠/展开光标所在的块 | — |
| `↑↓←→` / `Home` / `End` | 结构栏树导航 | 焦点在搜索框时只接管 ↑↓ |
| `Esc` | 关右键菜单、换类型菜单、Lightbox | 焦点在历史面板里时把焦点还给开关 |
