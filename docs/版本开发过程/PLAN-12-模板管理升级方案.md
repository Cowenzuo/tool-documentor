# PLAN-12 模板管理升级方案

> 状态：已定稿，待实施。范围是模板的身份、命名、引用与删除，以及由此带来的校验与界面调整。
> 底座一稳，现在堆在身份不稳上的一批同步与保护机制就能整批删掉。

## 1 目标

模板的身份与命名分开，引用只认 uuid，样式模板一律完整。身份稳定之后，重链接、覆盖度匹配、连带改写、备份回滚这类机制不再需要。

## 2 最小骨架

| # | 件 | 定 |
| --- | --- | --- |
| 1 | 身份 | 每份模板一个 uuid，程序生成，永不变，界面不显示 |
| 2 | 命名 | 中文名作主名，英文名作副名，可留空；名字纯展示，不参与匹配 |
| 3 | 存储 | `structures/<uuid>/<uuid>.json`；`styles/<uuid>/<uuid>.json` 与同目录下的骨架 |
| 4 | 引用 | 结构里只记一个默认样式 uuid，导出时任何一份样式都能选 |
| 5 | 默认样式在哪选 | 结构模板编辑的根节点详情页，原「样式对照表」那一节换成一个下拉框 |
| 6 | 解析 | 按 uuid 找样式；找不到就是悬挂 |
| 7 | 删除 | 删目录；引用它的结构显示悬挂，要求重选；导出被拒 |
| 8 | 清单 | 删掉。uuid 在每份模板自己的 json 里，目录名就是 uuid；要索引就扫目录生成 |

改名只写自己那一个 json，不碰文件、不碰引用、不碰别的模板。目录与文件名全用 uuid，代价是人眼翻目录看不出内容，已接受。

## 3 样式模板的完整性与回退

- 样式模板必须覆盖软件支持的全部样式键，共 18 个：标题 7、列表子标题 3、正文 1、图片 2、表格 3、列表首档 2；四个高阶列表键程序不读，不进要求。
- 校验按这个固定全集查缺键，与任何结构模板无关。
- 运行时若某个键缺失，一律按正文输出。
- 由此不存在不匹配的样式模板：任何结构配任何样式都能导出。

## 4 吸纳的地基

照搬不改：Word 骨架解析、样式映射表本身、结构模板的节点树与内容块模型、三栏编辑界面与卡片表单、锁、导出链路、原子写。

## 5 逐项去留

只留正确性与事实。

| 留 | 理由 |
| --- | --- |
| 原子写 | 防写到一半留下半截文件 |
| 导入的全有或全无 | 失败把本次铺开的东西收回，不留半成品 |
| 指针向骨架里不存在的 styleId 报错 | 配错了，与结构无关 |
| 校验、锁、缺样式拒导出 | 判定规则与既定口径 |
| 文件路径、悬挂标记 | 事实展示，不作机制 |

| 删 | 理由 |
| --- | --- |
| 按结构推导必需键 | 完整性改成按全集查，推导没有意义 |
| 结构所需逻辑键未覆盖那类结论 | 同上；`validateStyleTemplate` 不再收结构清单 |
| 可用集合与默认单选、共用提示 | 根节点那一节换成一个下拉框 |
| 另存为专用与 forkStyle | 复制就是新建一份带新 uuid 的模板 |
| 覆盖度匹配、悬挂降级、连带改写引用 | 引用只有 uuid，找不到就是悬挂，由用户重选 |
| 写前 `.bak`、备份目录、恢复入口、备份回执 | 可恢复性归版本控制；影子副本制造删了没删干净的假象 |
| 目录名等于 id、名字与文件名配对这类校验 | uuid 化后不存在这种匹配 |

## 6 非兼容与迁移

非兼容三处：目录与文件名、结构里的样式引用、清单。迁移做成产品里的动作：打开模板目录时识别旧格式并提示迁移，分配 uuid、改目录与文件名、把引用换成 uuid、去掉清单。旧格式不并存。本机脚本只用于开发期验证，不进产品。

## 7 差异盘点

| 层 | 现状 | 改动 |
| --- | --- | --- |
| 模板仓库格式 | 名字即身份，按文件名引用样式 | 全改 uuid，非兼容 |
| `packages/templates` | 按清单与名字解析；样式校验收结构清单 | 解析改 uuid；删清单与命名级规则；样式校验按全集查 |
| `template-editor-service` | 清单同步、另存为专用、备份与回滚 | 去掉这三样；新建生成 uuid；改名只写 json；删除只删目录 |
| 通道与 DTO | 入参多为 id 与 fileKey，含 fork-style | 入参换 uuid，去掉 fork-style |
| 渲染层 | 根节点显示样式对照表，引用按 fileKey | 换成一个下拉框；列表显示中英名；加悬挂提示与重选 |
| 导出对话框 | 只列声明引用的样式，标可用与不适用 | 列全部样式，默认选中结构里那份，可改选 |
| 模板库 | 现有几套模板 | 迁移一次 |
| 文档 | PLAN-03、PLAN-11 的引用口径，规范第 2 与第 4 节 | 相关段落重写 |

影响面最大的三处：模板仓库格式、templates 包的解析与校验、导出时的样式选择。

## 8 验收

1. 改名后除自身 json 外，模板目录里没有任何文件变动；
2. 任意结构配任意样式都能导出，样式告警为零；
3. 删掉一份样式后，用它的结构显示悬挂并要求重选，导出被拒；
4. 迁移后每份模板都能加载，校验结论与迁移前一致；
5. 应用数据目录里不再出现备份目录。

## 9 实施批次

1. 身份与存储：uuid、命名、目录与文件名、清单退场；
2. 解析与校验：按 uuid 解析，样式校验改按全集查；
3. 迁移动作；
4. 结构编辑界面：下拉框替换样式对照表那一节；
5. 导出对话框：全部样式可选；
6. 文档：PLAN-03、PLAN-11 与规范相关段落重写。
