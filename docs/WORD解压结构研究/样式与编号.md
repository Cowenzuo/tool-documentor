# 样式与编号

> 本页说明样式表怎么继承、字体怎么分槽位、编号与题注怎么产出。改导出链路的样式与
> 题注相关逻辑前先看这里，尤其是元素顺序与题注域那两节。

## 1. 样式继承

`styles.xml` 里每个段落样式可以声明 `basedOn`，形成一条继承链。没写 `basedOn` 的样式
从文档默认属性继承，也就是样式 `Normal`。这套继承是级联的，下游只覆盖自己声明的属性。

排查样式不生效时按链往上找。例如图题样式挂在图片段落样式上，图片段落样式又继承正文，
题注的字体就会跟着正文走，显式声明才会断开。

样式键与 styleId 的对应由样式模板的 stylemap 给出，代码里不写死 styleId。

依据：规范加实测。Word 回读确认继承链末端的实际字体与字号。

## 2. 字体槽位

`w:rFonts` 按字符类型分槽位，各管一段：

| 属性 | 管什么 |
| --- | --- |
| `w:ascii` | 西文字符与数字 |
| `w:hAnsi` | 高位西文，通常与 `w:ascii` 同值 |
| `w:eastAsia` | 中日韩字符 |
| `w:cs` | 复杂文种 |

中文报告的常规口径是中文用宋体或黑体，西文与数字用 Times New Roman，所以
`w:eastAsia` 与 `w:ascii` 要分别设置。只设 `w:eastAsia` 时其余槽位继续继承。

字号写 `w:sz`，单位是半磅，也就是 12 磅写 24。

依据：实测。Word 回读逐样式确认西文与中文两个槽位的实际字体。

## 3. 段落属性的顺序

`w:pPr` 的子元素顺序是规范强制的，不按顺序写，Word 会忽略位置不对的那个元素。

最常踩的是段落样式：`w:pStyle` 必须是 `w:pPr` 的第一个子元素。图片段落就栽过这一跟头，
样式写在 `w:jc` 之后，Word 直接当没有，图片段落落回正文体例。

常用的顺序片段：`pStyle`、`keepNext`、`numPr`、`spacing`、`ind`、`jc`、`outlineLvl`。

依据：规范加实测。改顺序前后用 Word 回读图片段落的样式名，结果不同。

## 4. 多级列表

标题编号用多级列表实现，结构是 `abstractNum` 定义层级，`num` 把它绑到一个 `numId`。

- 层级用 `w:ilvl` 表示，取值 0 到 8，**只到 8**。写 9 会让 Word 报文件损坏；
- 每层的 `w:lvlText` 用 `%1`、`%2` 这样的占位符引用各层当前值，标题的 `4.1.1` 就是这么拼的；
- 每层可以绑一个段落样式，绑上之后该样式的段落自动获得这一层的编号；
- 编号级别里的 `w:ind` 会盖掉段落样式的缩进。想让标题贴左边距，两处都要归零。

标题起始值由最底层的 `w:start` 决定。报告从第 4 章起编号时，这一项写 4。

依据：实测。层级写 9 时 Word 提示文件可能已损坏；缩进的两处来源分别验证过。

## 5. 层级填充会顶高标题计数

这是本工程最隐蔽的一个坑：与标题共用同一个 `numId` 的段落，如果层级比它后面的标题更深，
Word 会**补齐中间层级**，把标题的计数顶高一格。

具体表现：表题挂在第 7 层，位置在标题 2 之后、第一个标题 3 之前，于是第一个标题 3 从
`4.1.1` 变成 `4.1.2`，后面全跟着错。

结论：**任何与标题共用多级列表的题注层级都会污染标题计数**，换层级号也一样。
题注必须走域，或者由数据侧给出静态编号。

依据：实测。这条是真实工程里量出来的，静态编号之前一直复现。

## 6. 题注域

题注编号改用两个域组合，不再碰多级列表：

```
表{ STYLEREF "标题 2" \n }-{ SEQ 表 \* ARABIC \s 2 }  表名
图{ STYLEREF "标题 3" \n }-{ SEQ 图 \* ARABIC \s 3 }  图名
```

- `STYLEREF` 取最近一个指定样式段落的编号，也就是章节号；`\n` 表示只要编号不要文字；
- `SEQ` 是自增序号，`\s N` 表示在该层标题处重启，得到本节内的序号；
- 两者都不占用标题的多级列表，标题计数不再被污染；
- 域要带缓存值。导出时把算好的编号写进域里，Word 打开即显示正确，按 F9 可刷新。

### 样式名要写本地化名称

`STYLEREF` 只认样式在界面上的本地化名称。实测结果：

| 写法 | 结果 |
| --- | --- |
| `STYLEREF 4 \n`，用 styleId | 报错，提示文档中没有指定样式的文字 |
| `STYLEREF "heading 3" \n`，用骨架里的英文名 | 报错，找不到样式 |
| `STYLEREF "标题 3" \n`，用界面名称 | 得到 `4.1.1` |

所以样式名由样式模板显式配置，代码不猜。

### 与列表编号互斥

题注段落不能同时挂 `numPr`，也不能在 `numbering.xml` 里被绑到某一层。两者并存时
Word 会按列表编号，和域里的编号打架，出现两个号。

依据：实测。三种写法逐一在 Word 里跑过，按 F9 更新域后确认编号正确、标题计数未变。

## 7. 单倍与多倍行距

`w:spacing` 的 `w:line` 含义随 `w:lineRule` 变：`auto` 时单位是 240 分之一行，
写 360 就是 1.5 倍；`atLeast` 与 `exact` 时单位是二十分之一磅。

本工程的取值：正文与标题用 1.5 倍，题注与表格用单倍。

依据：实测。Word 回读逐样式的行距磅值确认。
