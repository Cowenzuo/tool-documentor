## 读法

动导出链路之前，先看《包结构与写入方式》里的部件级不变量，那里列了哪些部件可以重写、
哪些必须逐字节保留。改样式或题注，看《样式与编号》。碰图片、流程图对象，看
《图片与对象嵌入》。碰表格，看《表格与合并》。

每条结论后面都标了依据。标"实测"的，是拿真实模板导出后经 Word 打开确认过的；
标"规范"的，出自 ECMA-376 的部件与元素顺序定义。两者冲突时以实测为准，并在
`docs/WORD处理经验/` 里记一条坑位。

## 边界

- 本区只写与实现相关的结构事实，不收录素材原文与任何外部版权内容；
- 样本与素材不进仓库，回归只用 `samples/` 里的合成件；
- 结论要能被复现：写明模板、脚本与核对项，别人照着能跑出同样的结果。
